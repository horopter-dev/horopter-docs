---
title: Echo steps
description: A fixture tutorial of plain echo steps that the harness must pass.
---

A variable exported in one step is visible in a later one.

```bash run
export GREETING="hello from step one"
```

```bash run
echo "$GREETING"
```

```text expect
hello from step one
```

A directory entered in one step is the working directory of the next.

```bash run
mkdir work
cd work
```

```bash run
pwd
```

```text expect
.../work
```

A trailing `...` line allows output the page does not show.

```bash run
echo first
echo second
echo third
```

```text expect
first
...
```

This block is shown, not run.

```bash
exit 1
```
