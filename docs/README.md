# Working on the documentation site

These pages document this repository: how the site is built, checked and tested. The site's
own pages are MDX under `content/docs/`.

The site is Next.js and Fumadocs, exported as a static site and published to GitHub Pages.

- [Development](development.md): setting up, running the site locally, the reference import
  and the checks.
- [Tutorials](tutorials.md): how a tutorial's code blocks are run as its test.
